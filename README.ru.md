# MlPops

Инструмент поиска MLOps-вакансий и смежных DevOps/SRE-ролей с реальными ML-задачами. Интерфейс на русском и английском: фильтры, статистика технологий по текущей выборке, актуальность стека, история наблюдений, локальный профиль навыков и поиск работы.

**Текущее состояние:** кандидат для ревью. По умолчанию используется явно обозначенное демо с вымышленными работодателями. Реальный сбор и публикация пока не подтверждены. Прогноз не появляется без достаточной истории. [Результаты проверки](docs/VERIFICATION.md).

## Быстрый запуск

Нужны Python 3.12+, uv, Node.js 24+ и npm.

```sh
uv sync --locked
uv run python -m collector demo
cd web
npm ci
npm run dev
```

Откройте адрес сервера с путём `/ml_ops_vacancy/`. Переключатель RU / EN сохраняет язык в браузере и ссылке. На телефоне фильтры и статистика доступны отдельными вкладками.

Для проверки из корня проекта:

```sh
uv run ruff check collector analytics tests scripts
uv run pytest -q
uv run python -m collector validate web/public/data/demo.json
cd web
npm run check
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

## Реальные данные

Коллектор использует официальный API hh.ru, токен зарегистрированного приложения и контакт разработчика. Секреты передаются только через окружение; браузер получает подготовленный JSON. Шаблон — `.env.example`, он не загружается автоматически.

```sh
export HH_TOKEN='ВАШ_ТОКЕН'
export HH_USER_AGENT='MlPops/0.1 (ваш-контакт@ваш-домен.ru)'
uv run python -m collector collect --state state/real --output exports/market.json --days 30
```

Это локальный частный экспорт. Условия hh.ru ограничивают создание доступных третьим лицам баз и передачу данных: до публичной публикации необходимо документированное разрешение на конкретный сценарий. Флаг `--public` требует `HH_PUBLICATION_PERMISSION` со ссылкой на такое разрешение; наличие флага само по себе не даёт права публикации. Подробности — [API.md](docs/API.md).

История сохраняется на отдельной ветке `data`, а SQLite восстанавливается из текстового состояния. Ошибка сбора сохраняет последний корректный экспорт и сайт. Первичная инвентаризация не считается новыми вакансиями за день, пропуск сбора не равен нулю. Даты отчётов — Europe/Moscow. Зарплаты разных валют, периодов и налоговых баз не смешиваются.

Профиль навыков, заметки, избранное и отклики хранятся только в localStorage этого браузера. Для переноса используйте экспорт/импорт личной резервной копии. Общая ссылка содержит только публичные фильтры и язык.

## Публикация

Изменения находятся в одной feature-ветке; PR остаётся открытым для ревью. Автоматического слияния нет. После проверки и одного squash-слияния в `main` workflow публикует Pages официальными GitHub Actions. До слияния production не публикуется. [Настройка Pages и Secrets](docs/DEPLOYMENT.md). Если `DATA_MODE=real`, без разрешения, токена и первого успешного сбора публикация не выполняется; демо не подменяет реальные данные.
